Registration Flow

POST /api/auth/register
        |
        v
AuthController
        |
        v
UserService.register()
        |
        +----------------------------+
        | Check email already exists |
        +----------------------------+
                     |
             Yes --------> Throw UserAlreadyExistsException
                     |
                    No
                     |
                     v
        Encrypt Password using BCrypt
                     |
                     v
              Save User
                     |
                     v
          Return Success Response
Example Request: 
{
   "username":"admin",
   "email":"admin@gmail.com",
   "password":"admin123",
   "role":"ADMIN"
}

Login Flow

POST /api/auth/login
        |
        v
AuthController
        |
        v
UserService.login()
        |
        +-------------------------+
        | Find user by email      |
        +-------------------------+
                     |
            Not Found
                     |
                     v
     InvalidCredentialsException
                     |
                    Found
                     |
                     v
PasswordEncoder.matches()
                     |
              Password Wrong
                     |
                     v
     InvalidCredentialsException
                     |
             Password Correct
                     |
                     v
           Login Successful
Example Request: 
{
   "email":"admin@gmail.com",
   "password":"admin123"
}
